# 絶対に守るルール

このサイトを直したり足したりするときに、必ず守るルールです。ここに書いたことと食い違う変更をしたくなったら、先にこのファイルを更新してから作業します。

## コンセプト

- 未決定です。一言で言えるコンセプトを決めてから、配色、背景、ドット絵のスプライトを作ります。決まるまでは見た目の実装を進めません。
- 決まっていること: 夕方の秋の函館 + インターネット。連想させたいものは函館、秋 (紅葉など)、栗、インターネットです。配色は秋、栗 (まろん)、モンブランをイメージします。
- 時間帯は夕方です。otoneko.cat (深夜の海) とずらします。
- インターネットの要素 (古い OS のウィンドウなど) は otoneko.cat と共通にし、並んだときに別の場所の同じ世界に見えるようにします。
- ウィンドウは otoneko.cat の見た目 (ドットの欠けた角、縞のタイトルバー、右上の3つのボタン、開くアニメーション) をそのまま使い、変えるのは配色だけです。
- 見た目はコンセプトに沿わせますが、文章はコンセプトに寄せすぎません。演出の言葉は入れません。

## 文言と表記

- サイトの文言は日本語です。
- 名前は `まろん｡` です。キャッチコピーは「便利とロマンをシェアしよう」「思い立ったが吉日」で、一字一句このまま使います。
- 文言は短くし、余計な説明を足しません。自己紹介のニュアンスは本人の言葉を優先します。
- ボタンやリンクの文言は英語の短い語にします (`Link`、`More`)。
- UI に出すパスはスラッシュ区切りです。
- 所属、学年、経歴などの変わる情報は `src/data/profile.ts` に集め、部品の中には書きません。

## 載せる内容

- GitHub から取れるデータ (統計、作品、コントリビューション) は手書きしません。リクエスト時に取得します。
- 作品の説明文は GitHub の Description をそのまま表示し、カードでは2行で省略します。`Link` は GitHub の Website 欄から取ります。
- otoneko.cat への入口は、アカウント一覧の1行にせず独立した枠にします。文言は otoneko.cat 側 (`otnc-portfolio-v3` の `src/data/profile.ts` と `BottleMail.astro`) と食い違わないようにします。
- アクセスカウンターは置きません。

## ドット表現

- ドット絵 (アイコン、スプライト、背景の飾り) の1ドットは 3px にそろえます (CSS の `--dot`)。例外は自分のアイコンのディザだけです。
- ドット絵は回転させたり、整数倍以外に拡大縮小したりしません。
- 文字は PixelMplus をマス目の整数倍で使います。本文は PixelMplus10 を 20px、見出しは PixelMplus12 を 24px と 48px です (スマホでは 36px)。欧文も同じフォントです。
- 枠の角はドットの欠けた形を保ちます。`box-shadow` で角を四角く塗らず、影は `filter: drop-shadow()` で付けます。
- 色の境目の凸凹は、なめらかにうねる線にします。ザラザラした点描にはしません。

## 動き

- アニメーションは惜しまず、たくさん、凝って入れます。otoneko.cat 以上に動くサイトを目指します。
  - 背景は常に何かが動いている状態にします。
  - ウィンドウの開閉、ホバー、スクロールで現れる要素など、操作や表示のたびに反応を返します。
  - ドット絵のスプライトはコマ送りのアニメーションにします。
- アニメーションは基本的に `steps()` でカクカク動かします。例外は流れるメッセージのバナーで、`linear` でなめらかに、継ぎ目なく流し、最初は先頭のメッセージを画面中央に置きます。
- `prefers-reduced-motion` のときは、ループするアニメーションを止めます。
- 画面外のループアニメーションは止めます (`.is-paused`)。
- 動きを増やしてもページの軽さは守ります。重くなったら、質を落とさずに軽くする方法を先に探します。

## 技術

- Tailwind は使いません。React も、必要になるまで入れません。
- 共通の CSS は `src/styles/autumn.css`、部品だけのものは各 `.astro` の `<style>` に置きます。
- 部品はセクションごとに分け、ページは部品を並べるだけにします。
- Cloudflare は `devuloper` アカウントを使います。`mofumofupop` アカウントは使いません。
- 正規のドメインは `montblank.fun` (www なし) です。`www.montblank.fun` は 301 で転送します。
- `blog.montblank.fun` など他のサブドメインは、このリポジトリでは触りません。

## リポジトリ

- コード、識別子、コメント、コミットメッセージは英語です。ドキュメント (`docs/`) は日本語です。
- コミットに `Co-Authored-By` などの生成ツールの署名は付けません。
